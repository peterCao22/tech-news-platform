## 📝 使用指南

### 1. 个人阅读分析

2. 访问 `/history/personal`
3. 选择时间范围（7天/30天）
4. 查看我的TOP10、平台TOP10、对比分析

1. 访问 `/history/daily`
2. 选择日期（日历选择器）
3. 可选：按分类筛选
4. 可选：导出数据（JSON/CSV/Markdown）

### 3. 趋势分析
1. 访问 `/history/trends`
2. 选择时间范围（7天/30天）

4. 查看趋势方向（上升/下降/稳定）

### 4. 公司追踪
1. 访问 `/history/company`
2. 输入公司名称或股票代码
3. 选择时间范围（7天/30天）
4. 点击搜索查看新闻历史
5. 查看关注公司的最新动态

## 🔄 数据流程

### 趋势数据生成流程
```
1. 用户阅读内容 → UserReadingHistory
2. 每日定时任务 → aggregateKeywordTrends()
3. 聚合统计 → KeywordTrend / CategoryTrend
4. 前端查询 → getTrendReport()
5. 对比分析 → 计算变化趋势
```

### 个人分析流程
```
1. 查询用户阅读历史 → UserReadingHistory
2. 查询平台热门内容 → Content (按score排序)
3. 计算重叠内容 → Set intersection
4. 计算匹配度 → 重叠比例 + 排名相似度
5. 返回对比结果
```
