## 💡 设计亮点

### 1. 权重系统
不使用简单的开关，而是权重系统：
- 兴趣权重: 0.5 - 2.0x
- 关注权重: 1.0 - 3.0x
- 信息源权重: 0.1 - 2.0x

### 2. 评分透明度
用户可以看到个性化评分的调整原因：
```
基础评分: 85.5
+ 匹配兴趣(AI): +5.0
+ 关注公司(NVIDIA): +8.0
+ 信息源权重: +1.8
= 个性化评分: 100.3
```

### 3. 偏好模板
提供预设模板快速配置：
- AI投资者
- AI研究员
- 创业者
- 股票交易员
- 产品经理

### 4. 导入导出
便于备份和迁移：
```json
{
  "version": "1.0",
  "exportedAt": "2025-10-16T10:30:00Z",
  "preferences": {
    // 完整配置
  }
}
```
