# 个性化功能使用指南

## 📚 功能概览

个性化功能基于您的偏好设置，为您智能推荐最相关的科技新闻内容。

### 核心功能
1. **偏好设置** - 配置您的兴趣、关注和偏好
2. **个性化推荐** - 基于偏好的智能内容推荐
3. **每日TOP10** - 个性化的每日精选内容

---

## 🚀 快速开始

### Step 1: 配置偏好设置

1. **访问偏好设置页面**
   ```
   http://localhost:3000/settings/preferences
   ```

2. **选择兴趣领域**
   - 点击 "兴趣领域" Tab
   - 从预设标签中快速添加（如 AI、Blockchain等）
   - 或自定义添加您感兴趣的领域
   - 调整权重滑块（0.5x - 2.0x）

3. **添加关注**
   - 点击 "关注列表" Tab
   - 添加您关注的公司、股票或人物
   - 设置权重（1.0x - 3.0x）
   - 配置通知偏好

4. **配置信息源权重**
   - 点击 "信息源" Tab
   - 为不同信息源设置权重
   - 0.1x = 降低优先级
   - 1.0x = 默认优先级
   - 2.0x = 提高优先级

5. **设置显示和通知**
   - 配置内容类型偏好
   - 设置语言和时区
   - 配置通知频率

### Step 2: 浏览个性化内容

1. **访问个性化推荐页面**
   ```
   http://localhost:3000/personalized
   ```

2. **查看推荐内容**
   - 每篇内容显示基础评分和个性化评分
   - 评分提升说明您的偏好匹配度高
   - 点击 "查看详情" 展开评分调整详情

3. **使用过滤器**
   - 点击 "过滤" 按钮
   - 按分类筛选
   - 设置最低评分阈值
   - 点击 "应用过滤"

### Step 3: 查看每日TOP10

1. **访问TOP10页面**
   ```
   http://localhost:3000/personalized/top10
   ```

2. **浏览今日TOP10**
   - 查看排名（金银铜标识）
   - 阅读推荐原因
   - 展开评分调整详情

3. **查看历史TOP10**
   - 使用日期选择器
   - 浏览过去的TOP10内容

## 📊 理解个性化评分

### 评分计算公式

```
个性化评分 = 基础评分 
  + 兴趣匹配加权 (5分 × 权重)
  + 关注公司加权 (8分 × 权重)
  + 信息源权重 (基础分 × (权重-1.0) × 0.2)
  × 时间新鲜度 (0.8-1.1)
```

### 评分调整示例

```
📰 某AI新闻内容

基础评分: 85.5
+ 匹配兴趣(AI, 权重1.5): +7.5
+ 关注公司(NVIDIA, 权重2.0): +16.0
+ 信息源权重(TechCrunch, 1.2x): +1.7
× 时间新鲜度(12小时): ×1.05
━━━━━━━━━━━━━━━━━━━━━━━━
个性化评分: 100.0 (限制在100以内)
```

### 评分颜色说明

- 🟢 绿色 (80-100): 高质量内容
- 🔵 蓝色 (60-79): 良好内容
- 🟡 黄色 (40-59): 一般内容
- ⚪ 灰色 (0-39): 低质量内容

## 💡 使用技巧

### 1. 权重设置建议

**兴趣权重 (0.5-2.0x)**
- 0.5x: 降低不太感兴趣的领域
- 1.0x: 默认权重
- 1.5x: 比较感兴趣
- 2.0x: 非常感兴趣

**关注权重 (1.0-3.0x)**
- 1.0x: 一般关注
- 1.5x: 重要关注
- 2.0x: 高度关注
- 3.0x: 核心关注（不容错过）

**信息源权重 (0.1-2.0x)**
- 0.1-0.5x: 降低低质量来源
- 1.0x: 默认权重
- 1.2-1.5x: 提升优质来源
- 1.8-2.0x: 核心信息源

### 2. 偏好配置策略

**新手策略**
1. 先添加3-5个核心兴趣领域
2. 关注2-3家重点公司
3. 使用默认权重
4. 观察一周后再调整

**高级策略**
1. 添加10+兴趣领域，细化分类
2. 关注5-10家公司，设置差异化权重
3. 调整信息源权重，过滤噪音
4. 定期导出备份配置

### 3. 内容发现技巧

**使用过滤器**
- 按分类浏览特定领域
- 设置最低评分（如80+）只看高质量内容
- 结合搜索功能快速定位

**利用TOP10**
- 每天早上查看TOP10，快速了解重点
- 使用日期选择器回顾过去的热门内容
- 关注排名1-3的内容，通常质量最高

## 🎯 常见问题

### Q: 为什么有些内容评分降低了？

A: 如果内容与您的兴趣不匹配，或来自低权重信息源，个性化评分可能低于基础评分。

### Q: 如何让推荐更准确？

A: 
1. 添加更多具体的兴趣领域
2. 调整权重反映真实偏好
3. 设置信息源权重过滤低质量内容
4. 定期更新关注列表

### Q: TOP10每天什么时候更新？

A: TOP10基于当天的内容实时生成，您可以随时刷新查看最新结果。

### Q: 个性化影响内容列表吗？

A: 
- 标准内容列表 (`/content`) 不受影响
- 个性化推荐 (`/personalized`) 使用个性化评分
- 个性化TOP10 (`/personalized/top10`) 完全基于您的偏好

### Q: 如何重置偏好？

A: 目前需要手动删除各项配置。未来会提供一键重置功能。
